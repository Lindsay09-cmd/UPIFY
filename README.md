# UPIFY
**Upify es el Proyecto de Promoción de 2º BATÍN del CED Miguela Rodríguez: un sitio web de aprendizaje colaborativo donde los estudiantes preguntan, comparten recursos y se ayudan entre pares por materia. Incluye registro, materias, perfil, preguntas y respuestas con "mejor respuesta". App móvil y asistente de IA quedan para el futuro.
